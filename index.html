用法

1. 时间轴是4 行 × 9 列（昨晚21:00 → 明早08:00，每小时一张圆角卡片），卡片中间的白线把上/下半 hour 分开；红「现」标是此刻
2. 接着记：每次活动变了，点下方分类（或「记现在」），自动从上一格续到当前——不用再选起点终点
3. 睡眠 / 吃饭 / 洗漱选「生活/睡眠」——看得见，但不算进 学习/工作/娱乐/运动/社交 五类占比
4. 点时间带里任意格子，可单独改那一段（弹窗里用 +/− 调结束时间）
5. 昨天默认能补；手机上：浏览器打开 → 分享 → 添加到主屏幕
6. 云同步：设置里填一次 GitHub 令牌，点「☁️ 同步到云端」上传；换设备/手机打开后填同一个令牌、点一次同步即可拉取共用
